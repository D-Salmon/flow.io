# Source Fritzing compatible Flow.io 3.1.5

`FlowIO-Waveshare-3.1.2.fzz` est le schéma Fritzing du contrôleur autonome à
une seule Waveshare. Il documente les deux raccordements des températures et
rappelle que Qwiic reste actif dans les deux modes.

Le nom 3.1.2 correspond à la révision d’origine du dessin. Le raccordement n’a
pas changé en 3.1.5 ; le fichier sera renommé après validation du coffret final.

Le dessin est volontairement documentaire : il représente le câblage du
coffret et non un circuit imprimé à fabriquer. Le tableau détaillé et les
consignes électriques restent dans
[`../integration/schema-raccordement-waveshare.md`](../integration/schema-raccordement-waveshare.md).

Le dossier `source` contient le composant SVG et les sources XML utilisées pour
reconstruire le paquet `.fzz`.

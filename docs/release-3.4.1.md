# Flow.io Waveshare 3.4.1

Cette version publie le firmware Waveshare sous le numéro 3.4.1. Elle ajoute l’affectation configurable des fonctions aux relais CH1 à CH8.

Le firmware et l’image SPIFFS de cette version doivent être flashés depuis la même compilation. La version complète affichée par le contrôleur inclut la référence de build après `3.4.1`.
